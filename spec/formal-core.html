VarioHyve Language Specification

Formal Rules

This appendix gives the structural operational semantics (SOS) of the accepted core. Surface syntax and its explanatory examples are in Specification; Java representations and restrictions are in Java Interpreter. Unsettled parameters are listed at the end. No correctness or refinement theorem is assumed.

Signature and notation

\[ \begin{gathered} v,\rho\in A,\quad \sigma:A\rightharpoonup\mathit{Node},\quad u\notin A,\quad s=(n,k),\quad o=(C,i,\mu),\cr H:\mathit{Home}\rightharpoonup{\mathrm{method},\mathrm{slots},\mathrm{body},\mathrm{dead}},\cr X=(\sigma,H,B),\cr \kappa::=\mathrm{halt}\mid f::\kappa,\qquad K=\langle c,\rho,\kappa\rangle_X. \end{gathered} \]

\(A\) contains private runtime identities; \(u\) is uninitialized storage. \(B\) is the boundary state, including identity maps and canonical native null/Boolean identities. Failure is carried by the active control and is reported at the nearest callback boundary or independent entry. Fresh identities are always distinct from existing ones. An omitted configuration component is unchanged; \(X[\sigma(v).p:=w]\) denotes a field update, not a source assignment. \(\cdot\) concatenates sequences/stacks. For context-preserving steps, \(\langle c\rangle_X\) abbreviates \(\langle c,\rho,\kappa\rangle_X\) with the same \(\rho,\kappa\) on both sides.

Node or recordFields relevant to execution
\(\mathrm{Obj}(C,S,\rho_d,\Gamma)\)Class, physical slots, definition scope, member cache.
\(\mathrm{Act}(U,\rho_p,v,o,h)\)Generated local/parameter accessors, lexical parent, receiver, occurrence, return home.
\(\mathrm{View}(v,o,\rho_d)\)Declaration-relative receiver scope; no parameter bindings or return home.
\(\Lambda(\bar x,e,\rho_d,v,o,h)\)Native object of class Lambda, with code and private lexical captures.
\(\mu=(D,\rho_d,\bar x,T,\bar S,\bar D_m,e_b)\)Reified owned contribution: declaration, scope, formals, operations, slots, members, final initializer body.
\(\mathrm{Class}(\mu,\bar o,S,R,L,M)\)Owned contribution, direct applications, superclass, routes, complete layout, metaclass.
\(\mathrm{Meta}(\mu,\ldots)\)Class-side record; its fixed structural fields are given below. Not an eligible construction-clause target.
\(\mathrm{Alien}(\phi)\), \(\mathrm{Scalar}(p)\)Foreign identity or scalar payload; neither implies a native class.

Scopes use object accessors, not a separate binding environment. Every active scope carries receiver/origin/home metadata; a View has \(h=\bot\). \(\sigma(\rho).U\) is storage for generated accessors, not a source namespace. It retains declaration mutability: local bindings have setters; parameters do not. The maps below abbreviate these tagged storage declarations.

Class algebra

Let \(A_{\mathrm{cls}}\subseteq A\) contain identities whose store records are Class or Meta. The superclass field ranges over \(A_{\mathrm{cls}}\cup{\mathrm{Top}}\). The distinguished empty constructor \(\mathrm{Top}\notin A\) is not a store node, source value, lookup miss \(\bot\), uninitialized marker \(u\), or the canonical null identity.

The class algebra and its projection from realized classes are:

\[ \begin{aligned} Q&::=\mathrm{Top}\mid\mathrm{Apply}(\mu,Q),\cr \mathrm{shape}(\mathrm{Top})&=\mathrm{Top},\cr \mathrm{shape}(C)&=\mathrm{Apply}(\mu_C, \mathrm{Apply}(\mu_{o_1},\ldots \mathrm{Apply}(\mu_{o_m},\mathrm{shape}(S_C))\ldots)). \end{aligned} \]

For no direct applications the last equation is \(\mathrm{shape}(C)=\mathrm{Apply}(\mu_C,\mathrm{shape}(S_C))\); in particular, \(\mathrm{shape}(\mathrm{Object})=\mathrm{Apply}(\mu_{\mathrm{Object}},\mathrm{Top})\). This is a projection of instance-side composition, not an equality of runtime identities: occurrences, scopes, routes and metaclasses remain in their records. It introduces no intermediate classes. Every realized superclass chain is finite and ends at Top; only Object has Top as its direct superclass.

Top has no owned contribution, scope, class-of link or superclass projection. There is no value, allocation, factory or initializer-entry rule for it. Source construction-clause targets must be realized non-metaclass identities in \(A_{\mathrm{cls}}\); the seed supplies Object’s terminal superclass.

Core and machine controls

\[ \begin{aligned} e::={}&l\mid\mathrm{null}\mid ?\mid\mathrm{self}\mid\mathrm{outer}(D)\cr &\mid q.n(\bar e)_\iota\mid\lambda\bar x.e\mid\mathrm{class}(d)\mid\mathrm{object}(d)\cr &\mid\mathrm{let}(\bar b;e)\mid\mathrm{ret}(e)\cr &\mid\mathrm{alloc}(C)\mid\mathrm{init}(\tau;e_r,\bar e) \mid\mathrm{write}(j,e)\mid\mathrm{slotsDone},\cr q::={}&\mathrm{implicit}\mid\mathrm{explicit}(e)\mid\mathrm{super},\cr \iota::={}&\mathrm{exact}\mid\mathrm{invoke},\qquad b::=x\leftarrow e\mid_\leftarrow e. \end{aligned} \]

The return form \(\mathrm{ret}(e)\) is source ^e. Bare sends use exact/0; parentheses use invoke/k. Leading-dot sends lower to an explicit self receiver. The final four forms are private generated construction code. A class descriptor \(d\) retains owned declarations, contributor-target expressions and delayed routes. For \(\mathrm{object}(d)\), the descriptor is anonymous, with no owned constructor formals or factories; it may retain the same optional contributor clauses as a class descriptor.

The core form \(\mathrm{null}\) is an internal constant, not the source identifier null. Empty bodies and omitted initializers lower to this form; source null, true and false lower to ordinary implicit sends. Their results depend on lookup and the selected behavior, not on this constant rule or a reserved source spelling.

\[ \begin{aligned} c::={}&e\mid\mathrm{val}(v)\mid\mathrm{collect}(a;\bar v;\bar e) \mid a[\bar v]\cr &\mid\mathrm{call}(p,\bar v)\mid\mathrm{enter}(v,o,\bar x,\bar v,e,\chi)\cr &\mid\mathrm{steps}(\bar b;e)\mid\mathrm{return}(h,v)\cr &\mid\mathrm{member}(g)\mid\mathrm{foreign}(\omega) \mid\mathrm{callback}(v,n,\bar f)\cr &\mid\mathrm{error}(\epsilon)\mid\mathrm{abort}(\epsilon),\cr \chi::={}&\mathrm{method}\mid\mathrm{initializer}. \end{aligned} \]

\(a\) is a pending control with a value-list hole: a send, a private initializer entry, or class realization. Frames appearing below are exhaustive for these forms: Recv, Args, Bind, Restore, Done, Return, Write, Cache, Apply, Module, and Barrier. Their fields are given by their rules; the tail is \(\kappa\).

Runtime admission and conceptual control

The following transition rules describe ordinary execution under the sequential execution agreement. Their runtime-level admissibility condition is one conceptual control token \(\tau_c\) per live runtime, with one owner:

\[ \begin{aligned} \operatorname{owner}(\tau_c)\in{}&{\mathrm{idle}}\ &{}\cup{\mathrm{native}(\alpha)\mid\alpha\text{ admitted}}\ &{}\cup{\mathrm{foreign}(\iota)\mid\iota\text{ active}}. \end{aligned} \]

Here \(\alpha\) ranges over native continuations and \(\iota\) over foreign invocations. The condition ranges over one runtime’s evolving state and all its configurations, not separate tokens per configuration, stored version or thread. Ordinary native rules require ownership by their continuation; modeled foreign actions require ownership by their invocation. Transfers below are abstractly atomic, with associations retained in \(B\) and barriers. \(\tau_c\) is ghost state, not a required field or language value; initializer target \(\tau\) is unrelated.

Abstract eventRequired ownership transfer
Accepted independent entry or tooling readmissionidle to the selected new or prepared native continuation
Committed NF invocationNative caller to its fresh foreign invocation
Admitted callbackCurrent foreign invocation to the fresh callback continuation
Callback result or failure delivered at its barrierCallback continuation to the associated foreign invocation
Foreign done or fail deliveredForeign invocation to its suspended native caller, after admitted descendants finish
Independent final result or failure deliveredNative continuation to idle
Backend driver yields after a requested stepNative continuation to idle, retaining the successor for later readmission

All other ordinary steps retain ownership. Pending/rejected requests and completion arrival are adapter bookkeeping; done/fail below denotes delivery after descendant completion. The admission contract supplies nesting eligibility and rules out confusing a copied context with control ownership.

Backend one-step yield may leave a nonterminal successor without retiring its homes or producing a final observation. Later advancement requires readmission. The source evaluator’s driver instead retains authority between native steps until a boundary transfer or completion.

This layer models serialized control effects, not arbitrary foreign computation, host queues, wakeups or fairness. Such work can continue while a callback owns the token. Refinement must reconstruct ownership from the implementation; these conditions are not a completed proof of the Java coordinator.

The execution agreement also permits maintenance refinements and declared interventions. Maintenance may stutter; an intervention changing abstract state needs its own specified transition. The rules below define neither an intervention relation nor a parallel agreement. Proofs must state which extensions, if any, they include.

Evaluation

Literal interpretation \(B,\sigma\vdash l\Downarrow(v,\sigma’,B’)\) is fixed by the selected scalar profile; conversion failures use error. The internal null form returns the canonical identity \(v_{\mathrm{null}}\).

\[ \frac{B,\sigma\vdash l\Downarrow(v,\sigma’,B’)} {\langle l,\rho,\kappa\rangle_X\longrightarrow \langle\mathrm{val}(v),\rho,\kappa\rangle_{X[\sigma:=\sigma’,B:=B’]}} \]

\[ \begin{aligned} \langle\mathrm{null},\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(v_{\mathrm{null}}),\rho,\kappa\rangle_X,\cr \langle ?,\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{error}(\mathrm{Hole}),\rho,\kappa\rangle_X,\cr \langle\mathrm{self},\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(\sigma(\rho).v),\rho,\kappa\rangle_X. \end{aligned} \]

The self rule requires a receiver; absence is an error. For outer(D), let \(\rho_j\) be the first declaration-relative view for lexical declaration \(D\) in the retained lexical chain. No such view is InvalidOuter. The disputed deeper repeated-parent case is parameter O below.

\[ \frac{\sigma(\rho_j)=\mathrm{View}(v,o,\rho_d)\qquad \mu_o.D=D} {\langle\mathrm{outer}(D),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{val}(v),\rho,\kappa\rangle_X} \]

\[ \frac{w\text{ fresh}\qquad \sigma’=\sigma[w\mapsto\Lambda(\bar x,e,\rho,\sigma(\rho).v,\sigma(\rho).o,\sigma(\rho).h)]} {\langle\lambda\bar x.e,\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{val}(w),\rho,\kappa\rangle_{X[\sigma:=\sigma’]}} \]

Receiver and arguments

send retains its mode and origin: \(r=\mathrm{lex}(\rho)\), \(\mathrm{recv}(v)\), or \(\mathrm{super}(v,o)\). In the following first rule, \(q\in{\mathrm{implicit},\mathrm{super}}\), and \(r\) is lex(ρ) for implicit sends and super(σ(ρ).v,σ(ρ).o) for super; an absent required receiver/origin is an error.

\[ \begin{aligned} \langle q.n(\bar e)\iota,\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{collect}(\mathrm{send}(r,n,\square,\iota);[];\bar e), \rho,\kappa\rangle_X,\cr \langle\mathrm{explicit}(e).n(\bar e)\iota,\rho,\kappa\rangle_X &\longrightarrow\langle e,\rho,\mathrm{Recv}(n,\bar e,\iota,\rho)::\kappa\rangle_X. \end{aligned} \]

\[ \begin{aligned} &\langle\mathrm{val}(v),\rho’,\mathrm{Recv}(n,\bar e,\iota,\rho)::\kappa\rangle_X\cr &\quad\longrightarrow \langle\mathrm{collect}(\mathrm{send}(\mathrm{recv}(v),n,\square,\iota);[];\bar e), \rho,\kappa\rangle_X. \end{aligned} \]

\[ \begin{aligned} \langle\mathrm{collect}(a;\bar v;[]),\rho,\kappa\rangle_X &\longrightarrow\langle a[\bar v],\rho,\kappa\rangle_X,\cr \langle\mathrm{collect}(a;\bar v;e::\bar e),\rho,\kappa\rangle_X &\longrightarrow\langle e,\rho,\mathrm{Args}(a,\bar v,\bar e,\rho)::\kappa\rangle_X,\cr \langle\mathrm{val}(v),\rho’,\mathrm{Args}(a,\bar v,\bar e,\rho)::\kappa\rangle_X &\longrightarrow\langle\mathrm{collect}(a;\bar v\cdot[v];\bar e),\rho,\kappa\rangle_X. \end{aligned} \]

A class-target Args frame rejects each nonclass or metaclass result before advancing to the next target. Other argument lists retain values without executing their contents. These rules evaluate receivers/arguments once, left-to-right.

Local scope and sequencing

For \(\mathrm{let}(\bar b;e)\), allocate fresh \(a\) and \(\sigma’=\sigma[a\mapsto\mathrm{Act}(U,\rho,v,o,h)]\), where \((v,o,h)\) are copied from \(\rho\) and \(U={x\mapsto u\mid(x\leftarrow e_x)\in\bar b}\). All local names are reserved before the first initializer; duplicate names fail.

\[ \begin{aligned} \langle\mathrm{let}(\bar b;e),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{steps}(\bar b;e),a,\mathrm{Restore}(\rho)::\kappa\rangle_{X[\sigma:=\sigma’]},\cr \langle\mathrm{steps}([];e),\rho,\kappa\rangle_X &\longrightarrow\langle e,\rho,\kappa\rangle_X,\cr \langle\mathrm{steps}((x\leftarrow e_0)::\bar b;e),\rho,\kappa\rangle_X &\longrightarrow\langle e_0,\rho,\mathrm{Bind}(x,\bar b,e,\rho)::\kappa\rangle_X,\cr \langle\mathrm{val}(v),\rho’,\mathrm{Bind}(x,\bar b,e,\rho)::\kappa\rangle_X &\longrightarrow\langle\mathrm{steps}(\bar b;e),\rho,\kappa\rangle_{X[\sigma(\rho).U(x):=v]},\cr \langle\mathrm{val}(v),\rho’,\mathrm{Restore}(\rho)::\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(v),\rho,\kappa\rangle_X. \end{aligned} \]

For \(x=_\), the Bind rule discards the value and leaves storage unchanged. Source assignment remains a setter send. Empty bodies and missing initializers lower to the internal null form. Sequencing is a let with discard steps, not an additional binding discipline.

Selection

This section is the formal counterpart of message selection and lexical lookup.

\[ \begin{aligned} \mathrm{lin}(\mathrm{Top})&=[],\qquad L_{\mathrm{Top}}=\varnothing,\cr \mathrm{lin}(C)&=[(C,0,\mu_C)]\cdot\bar o_C\cdot\mathrm{lin}(S_C),\cr \mathcal R&={\bot}\cup{!\epsilon\mid\epsilon\in\mathit{Error}}\cup\mathit{Plan},\cr p&::=t\mid\mathrm{memberApply}(g,k),\cr t&::=\mathrm{get}(v,p_s)\mid\mathrm{set}(v,p_s)\cr &\quad\mid\mathrm{method}(v,o,\bar x,e)\mid\mathrm{lambda}(w)\cr &\quad\mid\mathrm{memberGet}(v,o,d)\mid\mathrm{foreignOp}(\phi,op). \end{aligned} \]

\(\bot\) is a miss and \(!\epsilon\) is an error. A plan is committed behavior. \(T_{v,o}(s)\) is the instantiated declaration table at occurrence \(o\): explicit methods override generated accessors at the same selector. Slot targets contain \(p_s=L_{\mathrm{class}(v)}(o,j)\); activation targets contain their local slot. Generated getters are get and memberGet. A lambda has intrinsic apply/k at its declared arity; other selectors use its native Lambda/Object hierarchy. Scalar tables are parameter S.

The recursive equation for \(\mathrm{lin}(C)\) applies only to realized class records. The empty base contributes no occurrence or slot mapping. Reaching it therefore uses the empty-list miss rules below for both exact and invocation search, including an exhausted super suffix; Top itself is never a receiver.

Exact and invocation lookup

Exact search over an ordered contribution list is:

\[ \begin{aligned} E(v,[],s)&=\bot,\cr E(v,o::L,s)&= \begin{cases}T_{v,o}(s)&T_{v,o}(s)\ne\bot,\cr E(v,L,s)&T_{v,o}(s)=\bot.\end{cases} \end{aligned} \]

For an Alien, \(E(v,s)\) instead uses effect-free adapter selection \(B\vdash\phi.s\Downarrow R\), translating a selected operation to foreignOp(φ,op) and retaining miss/error. No foreign getter is speculatively invoked. For native \(v\), \(E(v,s)\) starts at its complete hierarchy; an activation uses only its own accessor table. Write \(L_v\) for the receiver’s search list: \(\mathrm{lin}(\mathrm{class}(v))\) for native objects, including lambdas for non-apply selectors, and one accessor table for an activation. Lambda apply/k selects its intrinsic operation only at the declared arity; invocation retains the captures in the lambda rule below. Intrinsic apply has no invented method/contribution origin; inherited Object methods use their normal origin and the lambda object as receiver.

Exact callable eligibility excludes generated getters. Compute \(E(v,(\mathrm{apply},k))\) once and match its retained outcome against these cases:

\[ P(v,k)= \begin{cases} t&E(v,(\mathrm{apply},k))=t\text{ and }t\text{ is not a generated getter},\cr !\epsilon&E(v,(\mathrm{apply},k))=!\epsilon,\cr \bot&\text{otherwise}. \end{cases} \]

Let \(\eta\) retain successful accessor evidence for this invocation. The following ordered equations define generated-accessor eligibility \(A\); in the member row, \(g=\mathrm{memberGet}(v,o,d)\):

\[ \begin{aligned} A(g,k,\eta)&=\eta(g,k)&&\text{if defined},\cr A(\mathrm{get}(v,p_s),k,\eta)&= \begin{cases}!\mathrm{Uninitialized}&\sigma(v).S[p_s]=u,\cr P(w,k)&\sigma(v).S[p_s]=w,\end{cases}\cr A(g,k,\eta)&=\mathrm{memberApply}(g,k) &&g\text{ a member},\ k\in\mathrm{arities}(d),\cr A(g,k,\eta)&=\bot&&\text{otherwise}. \end{aligned} \]

Here storage notation includes activation slots. \(\mathrm{arities}(d)\) contains the selected member declaration’s constructor arity and owned apply factory arities; it neither consults the realization cache nor imports contributor factories.

Invocation search \(I(v,L,n,k,b,\eta)\) carries the getter-masking bit \(b\). In these rules set \(t=T_{v,o}(n,k)\), \(g=T_{v,o}(n,0)\):

\[ \begin{gathered} I(v,[],n,k,b,\eta)=\bot,\cr \frac{t\ne\bot\quad t\text{ not a generated getter}} {I(v,o::L,n,k,b,\eta)=t},\cr \frac{t=\bot\text{ or generated}\quad \neg b\quad g\ne\bot\quad A(g,k,\eta)=R\ne\bot} {I(v,o::L,n,k,b,\eta)=R},\cr \frac{t=\bot\text{ or generated}\quad b\ \lor\ g=\bot\ \lor\ A(g,k,\eta)=\bot} {I(v,o::L,n,k,b,\eta)=I(v,L,n,k,b\lor(g\ne\bot),\eta)}. \end{gathered} \]

For each occurrence, compute the unmasked \(A(g,k,\eta)\) at most once and match its retained outcome across the alternatives. Premises short-circuit left-to-right: never read a masked getter. All searches start with \(b=\mathrm{false}\). An ordinary n/0 method masks older getters without being executed to discover apply/k. A nearer eligible accessor can precede a farther exact method. Errors terminate selection.

Lexical receiver selection

For each scope \(\rho_i\), let \(D_i\) be its own declaration table and \(v_i\) its associated receiver: the activation itself or the receiver of a View. Define the eligibility judgment \(\rho_i\vdash(n,k,\iota)\Downarrow R_i\) by this ordered table. \(\checkmark(v_i,\eta)\) selects a receiver and evidence.

ConditionEligibility result
exact, \(D_i(n,k)\ne\bot\)\(\checkmark(v_i,\varnothing)\)
invoke, \(D_i(n,k)\) exists and is not a generated getter\(\checkmark(v_i,\varnothing)\)
invoke, \(D_i(n,0)\ne\bot\), \(g=E(v_i,(n,0))\) is an ordinary method, \(k=0\)\(\checkmark(v_i,\varnothing)\)
invoke, \(D_i(n,0)\ne\bot\), \(g=E(v_i,(n,0))\), \(A(g,k,\varnothing)=p\)\(\checkmark(v_i,{(g,k)\mapsto p})\)
An evaluated selection premise yields \(!\epsilon\)\(!\epsilon\)
Otherwise\(\bot\)

Walk lexical parents until the first nonmiss. On \(\checkmark(v_i,\eta)\), dispatch the original selector/mode on \(v_i\); do not execute the declaring operation directly. Invocation uses \(I(v_i,L_{v_i},n,k, \mathrm{false},\eta)\). Exhausting the lexical chain starts the same search on current self, or misses if no receiver exists. A final dispatch error/miss never resumes lexical search. Eligibility is thus established before an override can replace the eligible accessor route.

Explicit native sends start at the full receiver hierarchy. super(v,o) starts strictly after the executing occurrence \(o\), with fresh getter masking. The suffix is determined by occurrence identity, not by contribution equality. Explicit Aliens use adapter selection in either mode. Invalid native origins fail; foreign spellings self, outer, and super remain foreign selectors. Write \(r\vdash(n,k,\iota)\Downarrow R\) for this complete selection judgment.

\[ \begin{gathered} \frac{r\vdash(n,|\bar v|,\iota)\Downarrow p} {\langle\mathrm{send}(r,n,\bar v,\iota),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{call}(p,\bar v),\rho,\kappa\rangle_X},\cr \frac{r\vdash(n,|\bar v|,\iota)\Downarrow\bot} {\langle\mathrm{send}(r,n,\bar v,\iota),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{error}(\mathrm{MissingSelector}),\rho,\kappa\rangle_X}. \end{gathered} \]

A selected \(!\epsilon\) similarly enters error(ε). Eligibility evidence retains the callable target itself, including a selected foreign operation; call never rereads its getter or repeats adapter selection.

Calls and generated accessors

\[ \begin{aligned} \langle\mathrm{call}(\mathrm{get}(v,p_s),[]),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(\sigma(v).S[p_s]),\rho,\kappa\rangle_X,\cr \langle\mathrm{call}(\mathrm{set}(v,p_s),[w]),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(w),\rho,\kappa\rangle_{X[\sigma(v).S[p_s]:=w]},\cr \langle\mathrm{call}(\mathrm{method}(v,o,\bar x,e),\bar v),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{enter}(v,o,\bar x,\bar v,e,\mathrm{method}),\rho,\kappa\rangle_X. \end{aligned} \]

The getter requires a value other than \(u\); otherwise it enters error(Uninitialized). Setters exist only for writable declarations. For enter, arity must match. Allocate fresh \(a,\ell,h\):

\[ \begin{aligned} \sigma’&=\sigma[\ell\mapsto\mathrm{View}(v,o,\mu_o.\rho_d), a\mapsto\mathrm{Act}(\bar x\mapsto\bar v,\ell,v,o,h)],\cr H’&=H[h\mapsto \begin{cases}\mathrm{method}&\chi=\mathrm{method},\cr \mathrm{slots}&\chi=\mathrm{initializer}.\end{cases} \end{aligned} \]

\[ \begin{aligned} &\langle\mathrm{enter}(v,o,\bar x,\bar v,e,\chi),\rho,\kappa\rangle_X\cr &\quad\longrightarrow \langle e,a,\mathrm{Done}(h,v,\chi,\rho)::\kappa\rangle_{X[\sigma:=\sigma’,H:=H’]}. \end{aligned} \]

A method’s definition scope is the selected contribution’s scope, never its receiver’s own constructor activation. For a lambda, no fresh home is created:

\[ \frac{\sigma(w)=\Lambda(\bar x,e,\rho_d,v,o,h)\quad |\bar x|=|\bar v|\quad a\text{ fresh} \quad\sigma’=\sigma[a\mapsto\mathrm{Act}(\bar x\mapsto\bar v,\rho_d,v,o,h)]} {\langle\mathrm{call}(\mathrm{lambda}(w),\bar v),\rho,\kappa\rangle_X \longrightarrow\langle e,a,\mathrm{Restore}(\rho)::\kappa\rangle_{X[\sigma:=\sigma’]}} \]

Arity errors in a committed call are failures, not new lookup misses.

Class realization and construction

Definition, occurrences and layout

A descriptor’s target list is \(\bar e_d=[e_{A_1},\ldots,e_{A_m},e_S]\): direct mixins left-to-right, then an explicit superclass target. Omit \(e_S\) for implicit Object. Terminal constructor arguments remain in \(d.R\).

\[ \langle\mathrm{class}(d),\rho,\kappa\rangle_X \longrightarrow \langle\mathrm{collect}(\mathrm{realize}(d,\rho,\square);[];\bar e_d),\rho,\kappa\rangle_X. \]

Given validated target classes \(A_1,\ldots,A_m,S\), allocate fresh \(C,M\). Let \(\mu_C\) be \(d\)’s owned instance contribution capturing \(\rho_d\), \(o_i=(C,i,\mu_{A_i})\), and \(o_0=(C,0,\mu_C)\). The store extension is:

\[ \begin{aligned} \sigma(C)&=\mathrm{Class}(\mu_C,[o_1,\ldots,o_m],S,R_C,L_C,M),\cr \sigma(M)&=\mathrm{Meta}(\mu_C^{\mathrm{class}},[],\mathrm{Class},[],L_M,\mathrm{Metaclass}),\cr L_C(o,j)&=L_C(o’,j’)\ \Longleftrightarrow\ \mathrm{name}(o,j)=\mathrm{name}(o’,j’). \end{aligned} \]

\(L_C\) numbers distinct slot names in first-occurrence order through \(\mathrm{lin}(C)\), retaining a mapping for every logical slot. All inherited occurrences keep their original applying class. The class-side contribution contains only owned factories and generated new/default apply. With this extension \(\sigma’\):

\[ \langle\mathrm{realize}(d,\rho_d,[A_1,\ldots,A_m,S]),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{val}(C),\rho,\kappa\rangle_{X[\sigma:=\sigma’]}. \]

For implicit Object, insert that structural root without a source lookup. Declaration validity, reserved new, flat root seeding and factory signatures are the static constraints of Objects and Classes. For realized ordinary classes \(C\), including Object, Class, Metaclass and the shared Lambda class (not the semantic terminal Top):

\[ \begin{gathered} \mathrm{super}(\mathrm{Object})=\mathrm{Top},\quad \mathrm{super}(\mathrm{Class})=\mathrm{Object},\cr \mathrm{super}(\mathrm{Metaclass})=\mathrm{Class},\quad \mathrm{super}(\mathrm{Lambda})=\mathrm{Object},\cr \mathrm{class}(C)=M_C,\quad \mathrm{super}(M_C)=\mathrm{Class},\quad \mathrm{class}(M_C)=\mathrm{Metaclass}. \end{gathered} \]

Lambda values have class Lambda while retaining the record’s lexical captures. Lambda’s class has no public factories. Applications reuse the selected owned contribution’s identity; membership observations compare that identity with the supplied class’s owned contribution. IdentityMirror is an ordinary foreign capability governed by the observation contract; it adds no privileged machine transition.

Member-class cache

For \(g=\mathrm{memberGet}(v,o,d)\), the cache key is \(k_g=(v,o,d.D)\), with \(\Gamma(k_g)\in{\bot,\mathrm{busy},\mathrm{ready}(C),\mathrm{failed}(\epsilon)}\). Γ abbreviates the enclosing object’s private cache in \(\sigma\).

\[ \begin{aligned} \langle\mathrm{call}(g,[]),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{member}(g),\rho,\kappa\rangle_X,\cr \langle\mathrm{call}(\mathrm{memberApply}(g,k),\bar v),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{member}(g),\rho,\mathrm{Apply}(\bar v,\rho)::\kappa\rangle_X. \end{aligned} \]

\[ \frac{\Gamma(k_g)=\mathrm{ready}(C)} {\langle\mathrm{member}(g)\rangle_X\longrightarrow\langle\mathrm{val}(C)\rangle_X}. \]

For an absent entry, allocate fresh \(\ell\) with \(\sigma(\ell)=\mathrm{View}(v,o,\mu_o.\rho_d)\), and set \(\Gamma(k_g)=\mathrm{busy}\):

\[ \langle\mathrm{member}(g),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{class}(d),\ell,\mathrm{Cache}(k_g,\rho)::\kappa\rangle_{X’}. \]

\[ \begin{aligned} \langle\mathrm{val}(C),\rho’,\mathrm{Cache}(k_g,\rho)::\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(C),\rho,\kappa\rangle_{X[\Gamma(k_g):=\mathrm{ready}(C)]},\cr \langle\mathrm{val}(C),\rho’,\mathrm{Apply}(\bar v,\rho)::\kappa\rangle_X &\longrightarrow\langle\mathrm{call}(t,\bar v),\rho,\kappa\rangle_X &&P(C,|\bar v|)=t. \end{aligned} \]

busy raises CyclicRealization; failed(ε) raises that error without retry. Apply commits to the realized class’s exact callable operation: miss/error fails, never resumes outer lookup. A member that loses virtual dispatch or fails arity eligibility never enters these cache rules.

Generated constructor code

Let \(\tau=\mathrm{whole}(C)\) select the complete coordinator and \(\tau=\mathrm{owned}(o)\) select one owned contribution. With ; denoting the already-defined discard sequencing:

\[ \begin{aligned} I_\mu&=\mathrm{write}(0,e_0);\cdots;\mathrm{write}(r-1,e_{r-1}); \mathrm{slotsDone};e_b,\cr \mathrm{superRoute}(\mathrm{Top},[])&=[],\cr \mathrm{superRoute}(S,\bar a_S)&=[(\mathrm{whole}(S),\bar a_S)] \quad(S\in A_{\mathrm{cls}}),\cr R_C&=\mathrm{superRoute}(S,\bar a_S)\cdot[ (\mathrm{owned}(o_m),\bar a_m),\ldots,(\mathrm{owned}(o_1),\bar a_1)],\cr R_C&=[(\tau_1,\bar\beta_1),\ldots,(\tau_q,\bar\beta_q)],\cr I_C&=\mathrm{init}(\tau_1;\mathrm{self},\bar\beta_1);\cdots; \mathrm{init}(\tau_q;\mathrm{self},\bar\beta_q);I_{\mu_C},\cr \mathrm{new}_C(\bar x)&=\mathrm{let}(z\leftarrow\mathrm{alloc}(C), _\leftarrow\mathrm{init}(\mathrm{whole}(C);z,\bar x);z),\cr \mathrm{apply}C(\bar x)&=\mathrm{explicit}(\mathrm{self}).\mathrm{new}(\bar x){\mathrm{exact}}. \end{aligned} \]

Names \(z,\bar x\) in generated code denote exact accessor sends; \(z\) is fresh. An owned apply/k replaces the generated default at that arity. Object has no direct applications and its superclass is Top, so its dependency list is empty by superRoute. Its owned initializer is also empty; an empty implicit Object call may be omitted. No route targets Top and no initializer activation, return home or effects are created for it. The base equation admits no arguments; there is no \(\mathrm{whole}(\mathrm{Top})\) routine. A direct mixin imports neither its source class’s routes nor its other contributors. Source factories otherwise use ordinary method calls.

\[ \begin{aligned} \langle\mathrm{alloc}(C),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(v),\rho,\kappa\rangle_{X[\sigma(v):=\mathrm{Obj}(C,u^{|\mathrm{im},L_C|},\mu_C.\rho_d,\varnothing)]},\cr \langle\mathrm{init}(\tau;e_r,\bar e),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{collect}(\mathrm{initEntry}(\tau,\square);[];e_r::\bar e),\rho,\kappa\rangle_X,\cr \langle\mathrm{initEntry}(\tau,v::\bar v),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{enter}(v,o,\mu_o.\bar x,\bar v,I_\tau,\mathrm{initializer}),\rho,\kappa\rangle_X. \end{aligned} \]

Allocation requires a realized constructible \(C\) and fresh \(v\). For whole(C), \(o=o_0\), \(I_\tau=I_C\); for owned(o), \(I_\tau=I_{\mu_o}\). The coordinator’s route expressions and owned body share this single home; each nested dependency call gets its own. An object literal realizes its anonymous class and sends ordinary exact new/0:

\[ \begin{aligned} \langle\mathrm{object}(d),\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{explicit}(\mathrm{class}(d)).\mathrm{new}([])_{\mathrm{exact}}, \rho,\kappa\rangle_X. \end{aligned} \]

The ordinary receiver rule evaluates the class expression exactly once before dispatch. Its target expressions run in \(\rho\); routed arguments run in the fresh declaring initializer home after allocation. The resulting class and receiver are fresh on every evaluation. This introduces no additional private operation or object-specific continuation, and does not call apply or any contributor factory.

For a live current initializer home \(h\) with \(H(h)=\mathrm{slots}\), set \(v=\sigma(\rho).v\), \(o=\sigma(\rho).o\), and \(p_s=L_{\mathrm{class}(v)}(o,j)\) before evaluating the value expression:

\[ \begin{aligned} \langle\mathrm{write}(j,e),\rho,\kappa\rangle_X &\longrightarrow\langle e,\rho,\mathrm{Write}(v,p_s,\rho)::\kappa\rangle_X,\cr \langle\mathrm{val}(w),\rho’,\mathrm{Write}(v,p_s,\rho)::\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(w),\rho,\kappa\rangle_{X[\sigma(v).S[p_s]:=w]},\cr \langle\mathrm{slotsDone},\rho,\kappa\rangle_X &\longrightarrow\langle\mathrm{val}(v),\rho,\kappa\rangle_{X[H(h):=\mathrm{body}]}. \end{aligned} \]

Invalid private targets, arities or phases raise errors. No selector or Expat operation can name these controls.

Completion, return and failure

The rules below model the default boundary agreement, which prohibits non-local returns across foreign execution. Whether to support crossing belongs to the boundary agreement, not a universal native-language prohibition. A supporting agreement requires additional transfer rules; none are defined or implemented here. Lexical return targets, home liveness and initializer phase restrictions remain native rules.

\[ \frac{(\chi,H(h),v’)\in {(\mathrm{method},\mathrm{method},w),(\mathrm{initializer},\mathrm{body},v)}} {\langle\mathrm{val}(w),\rho’,\mathrm{Done}(h,v,\chi,\rho)::\kappa\rangle_X \longrightarrow\langle\mathrm{val}(v’),\rho,\kappa\rangle_{X[H(h):=\mathrm{dead}]}}. \]

An initializer finishing in slots raises PrematureCompletion. A source return first evaluates its operand, capturing \(h=\sigma(\rho).h\):

\[ \begin{aligned} \langle\mathrm{ret}(e),\rho,\kappa\rangle_X &\longrightarrow\langle e,\rho,\mathrm{Return}(h)::\kappa\rangle_X,\cr \langle\mathrm{val}(v),\rho,\mathrm{Return}(h)::\kappa\rangle_X &\longrightarrow\langle\mathrm{return}(h,v),\rho,\kappa\rangle_X. \end{aligned} \]

Let \(\kappa=P\cdot[\mathrm{Done}(h,w,\chi,\rho_c)]\cdot\kappa_c\), with no Barrier in \(P\). Successful delivery requires \(H(h)=\mathrm{method}\) or \(H(h)=\mathrm{body}\), according to \(\chi\). Let \(X’\) retire all homes in that prefix through the target and mark its pending Cache frames failed with AbandonedRealization:

\[ \frac{\kappa=P\cdot[\mathrm{Done}(h,w,\chi,\rho_c)]\cdot\kappa_c \qquad v’=\begin{cases}v&\chi=\mathrm{method},\cr w&\chi=\mathrm{initializer}\end{cases}} {\langle\mathrm{return}(h,v),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{val}(v’),\rho_c,\kappa_c\rangle_{X’}}. \]

Failure cases for this default agreement, checked before any successful-unwind mutation, are:

ConditionError
Missing or dead captured homeDeadContext
Live target lies below the first barrier (default no-crossing agreement)ForeignReturn
No matching completion frameDeadContext
Reachable target still has \(H(h)=\mathrm{slots}\)PrematureCompletion

Only completion of the target contribution is skipped; its caller’s subsequent contributions continue. A lambda’s captured home is never dynamically rebound.

\[ \langle\mathrm{error}(\epsilon),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{abort}(\epsilon),\rho,\kappa\rangle_X. \]

For an ordinary frame \(f\) (not Barrier), obtain \(X_f\) by retiring its home if it is Done, or caching failed(ε) if it is Cache; otherwise \(X_f=X\):

\[ \langle\mathrm{abort}(\epsilon),\rho,f::\kappa\rangle_X \longrightarrow\langle\mathrm{abort}(\epsilon),\rho,\kappa\rangle_{X_f}. \]

There is no rollback, lookup retry, or revival of a retired home. Aborting a callback retires only frames above its barrier; the suspended caller remains live. Cache failure caused by a successful return does not abort that return.

Alien/Expat transitions

The adapter state B includes call association and admission lifetime. The Java realization may obtain a callback from the operation thread or from a worker holding an explicit call context; admission serializes their native transitions. Each admitted callback belongs to the current foreign invocation, retains its suspended caller and budget, and creates the barrier below. Closing a foreign invocation disallows further callback actions for it and joins admitted descendants before delivering done or fail. Host requests rejected before admission do not create a native callback continuation. These rules describe the serialized native interaction; they do not formalize arbitrary parallel foreign actions, host waiting queues or a general scheduler.

These transitions use the default no-crossing agreement: callback entry installs Barrier, and the foreign action relation has no non-local-return transfer action. A future supporting boundary must define that transfer and its observable interaction with foreign execution; merely removing Barrier is insufficient.

The adapter provides stateful, identity-preserving conversions \(B,\sigma\vdash\bar v\Uparrow(\bar f,B’)\) and \(B,\sigma\vdash\bar f\Downarrow(\bar v,\sigma’,B’)\), or failure with the state reached before failure. Lists convert left-to-right. Exact canonical null/Booleans convert by identity; scalars follow S. Compatible identity round trips satisfy \(\Downarrow\Uparrow v=v\) and \(\Uparrow\Downarrow\phi=\phi\). These are boundary obligations, not privileged native service operations.

\[ \frac{B,\sigma\vdash\bar v\Uparrow(\bar f,B’)} {\langle\mathrm{call}(\mathrm{foreignOp}(\phi,op),\bar v),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{foreign}(op(\phi,\bar f)),\rho,\kappa\rangle_{X[B:=B’]}}. \]

The foreign interaction-state relation \(B\vdash\omega\leadsto(a,B’)\) has actions \(a::=\mathrm{done}(f)\mid\mathrm{fail}(\epsilon)\mid\mathrm{next}(\omega’) \mid\mathrm{send}(v,n,\bar f,\omega’)\). It may block or diverge; it need not be deterministic. The state \(\omega\) records foreign behavior and resumption; it is not the unique control token. Several suspended barriers can retain distinct foreign interaction states. Actions done and fail below mean completion delivery after the admission condition above is satisfied, not the physical arrival of an answer from a foreign worker. Its completion rules are:

\[ \begin{gathered} \frac{B\vdash\omega\leadsto(\mathrm{next}(\omega’),B’)} {\langle\mathrm{foreign}(\omega),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{foreign}(\omega’),\rho,\kappa\rangle_{X[B:=B’]}},\cr \frac{B\vdash\omega\leadsto(\mathrm{done}(f),B_1) \quad B_1,\sigma\vdash f\Downarrow(v,\sigma’,B_2)} {\langle\mathrm{foreign}(\omega),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{val}(v),\rho,\kappa\rangle_{X[\sigma:=\sigma’,B:=B_2]}},\cr \frac{B\vdash\omega\leadsto(\mathrm{fail}(\epsilon),B’)} {\langle\mathrm{foreign}(\omega),\rho,\kappa\rangle_X \longrightarrow\langle\mathrm{error}(\epsilon),\rho,\kappa\rangle_{X[B:=B’]}}. \end{gathered} \]

For callback action send(v,n,fs,ω′), allocate an empty activation \(a\) with no parent, receiver or home:

\[ \begin{aligned} &\langle\mathrm{foreign}(\omega),\rho,\kappa\rangle_X\cr &\quad\longrightarrow \langle\mathrm{callback}(v,n,\bar f),a,\mathrm{Barrier}(\omega’,\rho)::\kappa\rangle_{X’},\cr &\frac{B,\sigma\vdash\bar f\Downarrow(\bar v,\sigma’,B’)} {\langle\mathrm{callback}(v,n,\bar f),a,\kappa\rangle_X \longrightarrow\langle\mathrm{send}(\mathrm{recv}(v),n,\bar v,\mathrm{exact}),a,\kappa\rangle_{X[\sigma:=\sigma’,B:=B’]}}. \end{aligned} \]

Here \(X’\) includes the adapter step and fresh activation. Installing the barrier before import gives conversion failure the same failure path as the callback body. A previously handled failure does not prevent a new callback.

\[ \frac{B,\sigma\vdash v\Uparrow(f,B’)} {\langle\mathrm{val}(v),\rho’,\mathrm{Barrier}(\omega,\rho)::\kappa\rangle_X \longrightarrow\langle\mathrm{foreign}(\omega[\mathrm{result}(f)]),\rho,\kappa\rangle_{X[B:=B’]}} \]

\[ \langle\mathrm{abort}(\epsilon),\rho’,\mathrm{Barrier}(\omega,\rho)::\kappa\rangle_X \longrightarrow\langle\mathrm{foreign}(\omega[\mathrm{failure}(\epsilon)]),\rho,\kappa\rangle_X. \]

Export failure enters error with the barrier still present. The failed callback reports its diagnostic to the foreign continuation. Foreign code can handle it, make another callback and complete normally, or propagate a failure. The outer native caller observes that foreign completion after conversion; no shared fatal marker overrides it. Native mutations and callback-home retirement survive reentry, while suspended caller homes remain live until their own completion or failure. This does not resume the aborted callback or permit NLR crossing.

Conversion failures

Import failure has form \(!(\epsilon,\sigma’,B’)\); export failure has form \(!(\epsilon,B’)\), with unchanged native store. At each site the reached state is retained:

\[ \begin{gathered} \frac{B,\sigma\vdash l\Downarrow !(\epsilon,\sigma’,B’)} {\langle l\rangle_X\longrightarrow \langle\mathrm{error}(\epsilon)\rangle_{X[\sigma:=\sigma’,B:=B’]}},\cr \frac{B,\sigma\vdash\bar v\Uparrow !(\epsilon,B’)} {\langle\mathrm{call}(\mathrm{foreignOp}(\phi,op),\bar v)\rangle_X\longrightarrow \langle\mathrm{error}(\epsilon)\rangle_{X[B:=B’]}},\cr \frac{B,\sigma\vdash\bar f\Downarrow !(\epsilon,\sigma’,B’)} {\langle\mathrm{callback}(v,n,\bar f)\rangle_X\longrightarrow \langle\mathrm{error}(\epsilon)\rangle_{X[\sigma:=\sigma’,B:=B’]}},\cr \frac{B\vdash\omega\leadsto(\mathrm{done}(f),B_1) \quad B_1,\sigma\vdash f\Downarrow !(\epsilon,\sigma’,B_2)} {\langle\mathrm{foreign}(\omega)\rangle_X\longrightarrow \langle\mathrm{error}(\epsilon)\rangle_{X[\sigma:=\sigma’,B:=B_2]}}. \end{gathered} \]

\[ \frac{B,\sigma\vdash v\Uparrow !(\epsilon,B’)} {\begin{aligned} &\langle\mathrm{val}(v),\rho’,\mathrm{Barrier}(\omega,\rho)::\kappa\rangle_X\cr &\quad\longrightarrow \langle\mathrm{error}(\epsilon),\rho’,\mathrm{Barrier}(\omega,\rho)::\kappa\rangle_{X[B:=B’]} \end{aligned}}. \]

Entry, observations and remaining parameters

Normal module definition starts at an empty top activation, with structural superclass Object and no mixins; forbidden top-level contributor clauses fail before evaluation. Instantiation supplies existing argument values to exact new/k, without capturing the service’s scope. Tools may explicitly supply a different starting activation. See module entry. Independent entry requires successful runtime admission from idle under the control agreement above. Construction of an entry configuration does not itself grant execution authority. For a valid module descriptor \(d\), \(d\)’s arity must equal \(|\bar v|\). Allocate fresh \(a\) with \(\sigma’=\sigma[a\mapsto\mathrm{Act}(\varnothing,\bot,\bot,\bot,\bot)]\):

\[ \begin{aligned} \mathrm{module}(d,\bar v;X) &\leadsto\langle\mathrm{class}(d),a,\mathrm{Module}(\bar v)::\mathrm{halt}\rangle_{X[\sigma:=\sigma’]},\cr \langle\mathrm{val}(C),a,\mathrm{Module}(\bar v)::\mathrm{halt}\rangle_X &\longrightarrow\langle\mathrm{send}(\mathrm{recv}(C),\mathrm{new},\bar v,\mathrm{exact}),a,\mathrm{halt}\rangle_X,\cr \mathrm{tool}(e,\rho;X) &\leadsto\langle e,\rho,\mathrm{halt}\rangle_X. \end{aligned} \]

These are admitted independent entry points, not source operations. The entry arrow acquires the existing idle token for the new continuation. The same admission premise applies to independent exact Expat sends; callbacks instead use the foreign invocation’s admission path. A rejected module descriptor has no definition transition; it reports its validation error. Delivery of a Final observation returns control to idle; retaining the final configuration does not retain execution authority.

\[ \mathrm{Final}(K)= \begin{cases} \mathrm{success}(v)&K=\langle\mathrm{val}(v),\rho,\mathrm{halt}\rangle_X,\cr \mathrm{failure}(\epsilon)&K=\langle\mathrm{abort}(\epsilon),\rho,\mathrm{halt}\rangle_X. \end{cases} \]

The intended implementation relation \(R(J,K)\) reads the current Java store, decodes addressed frames and suspended callbacks, and preserves origins, homes, caches and active failure controls. It also reconstructs global control ownership from the Java coordinator and suspended calls; a permit object or copied callback context is not individually a control token. In the superclass field of root Object, it decodes Java’s absent reference as semantic Top, with no corresponding store identity. Other absent links retain their field-specific meanings. The terminal representation preserves the empty lookup, layout and construction cases. The relation is restricted to the supported scalar and sequential execution profile, with no unspecified interventions:

\[ R(J,K)\land J\longrightarrow_J J’ \ \Longrightarrow\ \exists K’.\ K\longrightarrow^*K’\land R(J’,K’). \]

Administrative stuttering must preserve result/error and boundary traces and must not hide divergence. The concrete choices and limitations are recorded once in implementation refinement.
