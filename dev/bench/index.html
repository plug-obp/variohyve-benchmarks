How to read these measurements

These are complete checked workloads, including applicable construction, execution and result validation. Parsing and warmup are excluded. Python and VarioHyve have different setup, lookup and boundary costs. GraalPy runs on the JVM with guest JIT disabled; Java compilation remains enabled.

Each point is one benchmark run. Branches share the timeline in measurement order; adjacent points can come from different branches and do not imply Git ancestry. Select a branch to follow its own history. Hosted runner hardware can vary.

Dots show means. In the spread view, boxes show the middle 50% of measured iteration means, the bar shows the median, and whiskers show the observed minimum and maximum. These describe iteration averages, not individual-operation latency or confidence intervals. Quartiles use linear interpolation across sorted samples. JMH's 99.9% confidence interval, when available, is shown separately in point details.

Older records have no samples and show a mean only. Their Python times (≈) are recovered from tooltip values rounded to three decimals; archived ratios retain their original precision. Missing data stays missing. Historical measurements before the explicit tracing profile are kept in a separate profile.

Sample distributions appear as workflows using the updated publisher complete. The raw download includes both the original archive and the new sample records.
