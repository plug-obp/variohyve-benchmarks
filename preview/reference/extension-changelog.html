Changelog

[0.6.1] — 2026-11-07

  • Bundle VarioHyve 0.6.1 with corrected installed help, public support routes, composition lessons, license notices and actionable Java startup guidance.

[0.6.0] — 2026-11-07

  • Bundle the VarioHyve 0.6.0 runtime, language server and packaging tools.
  • Support bracket constructors, private/immutable declaration defaults and explicit values.
  • Ship the consolidated 0.6.0 lessons and matching recipe templates.

[0.4.0] — 2026-10-16

  • Bundle VarioHyve 0.3.0 and the native packaging tools with the smaller runtime dependency set.
  • Add New Recipe Project, Run Recipe, Package Application and Run Deployment.
  • Route Run/Test through explicit recipe launch configuration when present, including native test status and execution budgets.
  • Save imported source revisions before launch and report failures against their matching source snapshots.
  • Support project-owned Alien packages and an independently reusable native package through the complete installed extension journey.
  • Keep imported recipe-module assistance conservative through an inert project marker; never execute recipes for completion.

[0.3.0] — 2026-10-12

  • Bundle the VarioHyve 0.2.0 runtime and language server, including releasable Expat receipts.
  • Add Evaluate Selection in Scratch and Evaluate Scratch commands with isolated expression runs.
  • Improve assistance status, untitled editing, literal API help, folding, selections and server shutdown.
  • Preserve the selected file across asynchronous launches; fix Stop, terminal input and stale diagnostic races.
  • Correct UTF-16 source ranges, cascade diagnostics and descriptor framing.
  • Highlight opaque method-header and trailing descriptors distinctly from executable code; preserve the user’s theme.

[0.2.0]

  • Package matching JavaHostKernel application runner, SUnit and API declarations.
  • Add explicit Run, Test, Stop and Restart commands, workspace trust and Java checks.
  • Add snapshot-safe runtime Problems and contract-based completion, signatures, hover and navigation.
  • Correct starter snippets and preserve the selected editor theme.

[0.1.0]

  • Initial scaffolding: syntax highlighting, diagnostics, document symbols, snippets
