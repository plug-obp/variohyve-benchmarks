LEARN VARIOHYVE · V0.1.0

Learn VarioHyve

Welcome! Let's build small programs that greet someone, convert a temperature, count words and keep score. Along the way you will learn how VarioHyve objects communicate by sending messages, and how a program receives the tools it needs.

Start with Install and say hello. Each chapter has a complete example you can open, run and change.

  1. Install and say hello
  2. Values, messages and input
  3. Arithmetic and choices
  4. Repetition and collections
  5. Objects that remember
  6. Test your program
  7. Add a capability written in Java
  8. Call VarioHyve from Java

The examples folder contains every complete program and its input and output fixtures. The starter reference collects details for when you need them. You do not need to read it before writing your first program.

These lessons use the Host Seed with JavaHostKernel. The kernel gives us familiar numbers, text, collections and a console. A capability is simply a tool a program is given: our first program receives a console through its kernel input.

Contributors can check the actual lesson files with python3 scripts/check-learn.py --distribution vh-host/build/install/vh-host from the repository root after building the starter distribution. The checker also compiles the Java lessons against the packaged jars.
