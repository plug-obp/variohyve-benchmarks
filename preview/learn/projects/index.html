LEARN VARIOHYVE · V0.3.2

Recipe lesson files

Lesson 9 displays and links these exact copies of the shipping recipe-project files:

  • Main.vh: application behavior.
  • World.vh: native construction and development entries.
  • Tests.vh and SuiteReporter.vh: assertions and native reporting.
  • Main.vh.launch.json: editor and command-line launch configuration.
  • Package.vh: production inventory and entry.
  • .variohyve-project: the editor's project marker.

Create the working project from the installed tools or New Recipe Project first. These individual downloads replace its editable files; they do not include the SUnit library or packaged console and value-adapter JARs. The independent native multiplier package supplies the project's packages/multiplier dependency.

Lesson 10 supplies complete alternative World.vh and Package.vh files for the custom Alien exercise. Copy them under those same names in the existing project after building the provider described by the lesson. The application, tests and launch sidecar stay unchanged.

These recipe files are separate from the starter examples, which use the earlier lessons' JavaHostKernel. Source checks compare the complete lesson blocks with these downloads and the recipe copies with the shipping project. The archive journey tests their installed counterparts outside the checkout.
