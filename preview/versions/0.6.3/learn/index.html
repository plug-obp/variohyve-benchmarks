LEARN VARIOHYVE · V0.6.3

Learn VarioHyve

Welcome! Let's build small programs that greet someone, convert a temperature, count words and keep score. Along the way you will learn how VarioHyve objects communicate by sending messages, and how a program receives the tools it needs.

Start with Install and say hello. Each chapter has a complete example shown inline, with a download link so you can run and change it.

Your first small programs

Lessons 1–6 take you from a greeting to objects you can test. Finishing them is a useful first milestone: you can write, change and check a small program.

The starter examples folder contains the first eight lessons' programs and their input and output fixtures. The recipe lesson files contain the complete application, recipes, tests and launch configuration from lessons 9 and 10. Each lesson shows its files inline and links their downloads. The starter reference collects details for when you need them. You do not need to read it before writing your first program.

This edition accompanies VarioHyve 0.6.3. Use its matching downloads: earlier previews may use different declaration and constructor syntax.

The first eight lessons use the Java starter with JavaHostKernel. Lessons 9 and 10 assemble explicit recipe worlds and package their dependencies. The kernel gives us familiar numbers, text, collections and a console. A capability is simply a tool a program is given: our first program receives a console through its kernel input. The language essentials collect the rules used throughout the lessons. The runtime guide explains how this starter relates to the Lean native implementation.

Lesson 11 brings the pieces together in a small review desk with a replaceable checker and a shared notebook.

Contributors can check the actual lesson files with python3 scripts/check-learn.py --distribution vh-host/build/install/vh-host from the repository root after building the starter distribution. The checker also compiles the Java lessons against the packaged jars.

The native multiplier package is a separate producer folder used by the packaging archive journey; it is not an additional starter-kernel lesson.
