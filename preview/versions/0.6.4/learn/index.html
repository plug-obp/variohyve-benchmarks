LEARN VARIOHYVE · V0.6.4

Learn VarioHyve

Build small programs, run them, and make them your own. Start with Install and say hello; each lesson includes a complete example, a download and a small change to try.

Your first small programs

Begin here. These six lessons take you from a greeting to objects you can test.

  1. Install and say hello
  2. Values, messages and input
  3. Arithmetic and choices
  4. Repetition and collections
  5. Objects that remember
  6. Test your program

That is a useful first milestone: you can write, change and check a small program. Try a few ideas of your own, or continue when you feel ready.

Build useful programs

Use the same starter to make a shop receipt, grow a stock report, and connect components you can test. Each lesson builds on the previous one.

  1. Give each step a name
  2. Build a stock list
  3. Find what needs restocking
  4. Pass a small piece of behavior
  5. Bring components together
  6. Test collaborating objects

You can now organize a small application and check how its pieces work together.

Go further when you need it

These lessons are optional. Choose Java integration when you have an existing tool to connect, or application packaging when you want to share a program.

  1. Add a capability written in Java
  2. Call VarioHyve from Java
  3. From starter to your own world
  4. Publish and consume a tiny native package

Keep the starter reference handy while editing. The runnable examples and recipe projects collect the lesson files and contributor checks.
