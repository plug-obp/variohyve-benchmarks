FROM DOWNLOAD TO HELLO

Make something run.

The starter includes learn/: lessons and complete programs to open, change and test. Later chapters introduce native recipes and packages.

Read Learn VarioHyve ↗

  1. Extract your starter.

    Check that java -version and javac -version select JDK 23 or newer. Set JAVA_HOME to that JDK and put its bin directory on your PATH.

  2. Open the learn folder.

    In VS Code, choose Extensions: Install from VSIX… and select the downloaded extension. Open learn and trust the folder to enable running programs.

  3. Run your first program.

    Open examples/hello.vh, then choose VarioHyve: Run File. Later, use VarioHyve: New Recipe Project to choose your own dependencies.

Prefer a terminal?

From the extracted starter's learn directory:

macOS / Linux

../bin/vh run examples/hello.vh
../bin/vh test examples/tests/lessons.vh

Windows PowerShell

..\bin\vh.bat run examples\hello.vh
..\bin\vh.bat test examples\tests\lessons.vh

SMALL, USEFUL BUILDING BLOCKS

Start simple. Keep going.

  • Numbers, text and collections. Learn messages, objects, input and state with complete examples.
  • Tests from the start. Write SUnit assertions, run them from the terminal or VS Code, and distinguish a failed assertion from a failed execution.
  • Explicit capabilities. Move from the ready-made starter kernel to native recipes, native package dependencies and packaged Java providers.

BUILD AND VALIDATION RECORD

Know what you are trying.

These are locally built downloads from the exact v0.6.1 source tag. The manifest identifies their bytes, checksums, commands and platform scope. Hosted CI did not start validation: Linux/Windows jobs were blocked by account billing limits and the macOS runner configuration was unavailable.

Windows and Linux x86_64 are not validated for this patch. The Java minimum is JDK 23; test versions are listed below. This remains an early preview: debugging and general type inference are outside this release.
