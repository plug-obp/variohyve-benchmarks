NEW IN 0.2.0

Better tools. Explicit lifetimes.

  • Alien GC and explicit detach. Java clients use releasable receipts for native objects; adapters explicitly retain callbacks beyond an invocation. The embedding lesson shows the updated API.
  • A clearer editor. Improved Unicode diagnostics, API help, assistance status and metadata highlighting, plus fixes to Run, Stop and terminal input.
  • Try an expression. Evaluate a selection in an independent, editable scratch document, then change it and run again.

Upgrading a Java adapter? Read the changelog and migration notes. Arbitrary cross-boundary cycles still require explicit release or cooperation.

FROM DOWNLOAD TO HELLO

Make something run.

Your archive includes learn/: eight short chapters and complete programs to open, change and test.

Read Learn VarioHyve ↗

  1. Extract your starter.

    Check that java -version and javac -version select Java 23. Set JAVA_HOME to that JDK and put its bin directory on your PATH.

  2. Open the learn folder.

    In VS Code, choose Extensions: Install from VSIX… and select the downloaded extension. Open learn and trust the folder to enable running programs.

  3. Run your first program.

    Open examples/hello.vh, then choose VarioHyve: Run File in the Command Palette. Output appears in the integrated terminal. If Java isn’t found, set vh.javaHome to your JDK folder.

Prefer a terminal?

From the extracted starter’s learn directory:

macOS / Linux

../bin/vh run examples/hello.vh
../bin/vh test examples/tests/lessons.vh

Windows PowerShell

..\bin\vh.bat run examples\hello.vh
..\bin\vh.bat test examples\tests\lessons.vh

SMALL, USEFUL BUILDING BLOCKS

What’s in this preview?

  • Numbers, text and collections. Send messages such as 2.plus(3), work with lists and maps, and read and print console input.
  • Tests from the start. Register named cases and use simple SUnit assertions. Run them from the terminal or VS Code.
  • Java, in both directions. Follow examples that add a Java capability and call VarioHyve from a Java application.
